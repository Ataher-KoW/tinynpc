# TinyNPC v1.0: local NPC dialogue for games

I wanted small NPCs I could actually talk to. This is the newest student fine-tune, chosen after trying it in my game. It is **1.28 GB**, runs locally, and takes the character description, player message, memory and visible scene facts as context.

Only the student model and developer integration are included. Bring your own game and speech services. POV means structured observations supplied by your game, not raw image understanding.

## Try it

Windows x64, NVIDIA GPU, Python 3.10 or newer:

```powershell
git clone https://github.com/Ataher-KoW/tinynpc.git
cd tinynpc
python -m inference.setup --runtime windows-cuda
python -m examples.chat
```

Setup downloads ten checksum-verified parts and assembles the model. The native runtime downloads separately. Allow 6 GB free during setup. Existing users should pull the new source and rerun setup; v1.0 uses a new model filename, so it does not overwrite the previous weights.

Define your NPC with the JSON examples in [the character guide](https://github.com/Ataher-KoW/tinynpc/blob/main/docs/characters.md). Add your game's visible entities and the player's message. See [Python and HTTP integration](https://github.com/Ataher-KoW/tinynpc/blob/main/docs/integration.md).

## What the measurements say

Measured on my **RTX 2060 6 GB**. Warm text inference only: model loading, speech recognition and speech synthesis are excluded. Other hardware is unmeasured.

| Development measurement | Previous baseline | v1.0 preference fine-tune |
|---|---:|---:|
| Mean reply time, 100 scripted conversations | 0.383 s | 0.494 s |
| Mean reply length in that test | 8.50 words | 15.25 words |
| Failed conversations in that test | 1 | 0 |
| Narrow fact checks, separate 320-turn stress test | 24/24 | 19/24 |
| Short reply p95, stress test | 0.380 s | 0.587 s |
| Complete reply p95, stress test | 0.464 s | 0.670 s |
| Stress-test replies below one second | 100% | 100% |

The whole-conversation AI preference score was **0.750**, calculated as `(51 wins + 0.5 * 48 ties) / 100`, with one loss. The family-bootstrap 95% interval was 0.694 to 0.813. This is a development result from an AI judge, not a human-quality percentage or an independent final benchmark. The teacher also contributed training data. There are no blinded human preference scores.

The automatic selection kept the baseline because the new fine-tune missed five narrow corrected-name/current-view checks and exceeded the allowed short-reply slowdown. I preferred the new model in my own game and chose it for this release. That is a personal judgment, not proof those regressions are solved. All 320 stress-test replies completed without generation failures.

The fact checks are literal and narrow, not semantic accuracy. Repeated scripted turns are correlated. A result under one second here is not a guarantee for every prompt or machine.

The 600-case test elsewhere in the completed run evaluated the automatically selected baseline, not these preference weights. Older IFEval, quality and speed graphs belong to earlier models and must not be attributed to v1.0.

## Demo and files

The release includes a captioned response demo of at least 40 seconds and its exact transcript. The game and audio services were not my focus. I made a simple game to show the model. Demo pacing is edited for reading; it is not a continuous latency benchmark.

Model size: **1,282,438,944 bytes**, or 1.282 GB / 1.194 GiB. The manifest and SHA256SUMS.txt identify the exact weights and each download part. No teacher or speech weights are shipped.

Code: MIT. Modified student model: Apache-2.0. See the model card and model license attached to this release. The model can still invent details, forget corrections and give awkward replies. Keep important game state under your game's control.
